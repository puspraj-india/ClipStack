# ClipStack

A small, browser-based clipboard history. Paste text into the box (or use **Paste from clipboard**) and save it to keep it in your recent clips. Use **Copy** to put a clip back on your clipboard, or delete individual clips and clear the full history.

ClipStack stores up to 50 clips in the current browser's local storage. Clipboard access requires browser permission and a secure context (such as `localhost`); you can always paste directly into the text box instead.

To use it, open `index.html` in a browser. No install or build step is needed.
